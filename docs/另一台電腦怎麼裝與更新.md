# 另一台電腦（例如公司電腦）怎麼裝與更新

給「防毒（例如 Kaspersky）會擋 `install.ps1`」的電腦用。**這份做法完全不跑 `install.ps1`**，也不需要系統管理員權限：

- 程式直接放在你抓下來的資料夾裡，不複製到別處。
- 只有第 5 步會動到你的 Claude 設定檔（`settings.json`），而且動之前先備份。
- 如果任何一步被防毒擋住：**停在那一步**，把警告畫面截圖，問資訊部門。不要自己按「允許」、不要關防毒、不要想辦法繞過去。

## 事前準備（只要做一次）

1. 按鍵盤的 Windows 鍵，打 `cmd`，按 Enter，開啟黑色的「命令提示字元」。
2. 打 `node -v` 按 Enter。看到 `v18` 以上的數字（例如 `v20.11.0`）就可以。顯示「不是內部或外部命令」＝沒裝 Node.js，要先裝 LTS 版（https://nodejs.org）再重開命令提示字元。**一定要有 Node.js**：掃描和 hook 都靠它，沒有的話小工具會顯示「找不到 Node.js」。
3. 打 `git --version` 按 Enter。看到 `git version …` 就可以。沒裝 Git 的話，改用網頁下載壓縮檔：打開 https://github.com/Pla821/pending-decisions-widget → 綠色按鈕「Code」→「Download ZIP」→ 解壓縮到 `C:\Users\你的使用者名稱\pending-decisions-widget`（資料夾名稱要保留 `pending-decisions`），然後跳到第 3 步。**用壓縮檔的話，之後更新要整包重抓**（見最下面）。

## 安裝

1. **抓程式。** 在命令提示字元依序打（每行按一次 Enter）：

   ```
   cd %USERPROFILE%
   git clone https://github.com/Pla821/pending-decisions-widget.git
   cd pending-decisions-widget
   ```

   如果跳出要你登入 GitHub 的視窗，用你自己的 GitHub 帳號登入。完成後你會有資料夾 `C:\Users\你的使用者名稱\pending-decisions-widget`。**這個資料夾以後不要搬家、不要改名**（hook 會記住它的位置）。

2. **先把小工具跑起來看看。** 在檔案總管打開上面那個資料夾，連點兩下 `start-widget.cmd`。幾秒後，螢幕角落會出現一個小圖示（沒出現的話看最下面「出問題時」）。
   - 如果跳出防毒警告：停在這裡，見最前面的說明。

3. **開機自動啟動（選用）。** 連點兩下 `install-startup.cmd`。它只會在你自己的「啟動」資料夾放**一個捷徑**，什麼都不複製、不改設定。看到「Done. The widget will start at your next logon.」就成功了，按任意鍵關掉視窗。想取消就連點兩下 `uninstall-startup.cmd`。

4. **（選用）放設定檔 `config.json`。** 不放也能用，通知預設全開。要放的話：
   1. 在檔案總管打開資料夾 `pending-decisions-widget` → 再打開裡面的 `src` 資料夾。**設定檔要放在 `src` 裡面**，路徑是 `…\pending-decisions-widget\src\config.json`。
   2. 在空白處按右鍵 →「新增」→「文字文件」，取名 `config.json`（如果看不到副檔名，檔案總管上方「檢視」→「顯示」→勾「副檔名」，確定名字沒有變成 `config.json.txt`）。
   3. 用記事本打開，貼上下面這段，存檔（編碼選 UTF-8）：

      ```json
      {
        "toast": true,
        "theme": "auto",
        "notify": { "permission": true, "question": true, "wrapup": true, "proposal": true, "fable": true, "usage": true }
      }
      ```

      想關哪一種通知，就把那一個 `true` 改成 `false`（說明見 [通知時機.md](通知時機.md)）。這個檔不會被 `git pull` 蓋掉，也不會被推上 GitHub。
   4. 改完 `usage` 要重開小工具（見「更新」第 2 步）；其他的下一次通知就生效。

5. **把 hook 接進 Claude（讓 Windows 通知和「要你允許」生效）。** 沒有這一步，小工具仍然看得到選項框、提問卡、建議任務卡片，但**不會跳 Windows 通知，也看不到「要你允許」**。

   **5-1　備份。** 在命令提示字元（還在 `pending-decisions-widget` 資料夾裡）打：

   ```
   if exist "%USERPROFILE%\.claude\settings.json" if not exist "%USERPROFILE%\.claude\settings.backup-before-pdw.json" copy "%USERPROFILE%\.claude\settings.json" "%USERPROFILE%\.claude\settings.backup-before-pdw.json"
   ```

   這行不會蓋掉已經存在的備份。看到「已複製 1 個檔案」＝備份好了。（沒有任何訊息也可能是你本來就沒有 settings.json 或之前備份過，可以繼續。）

   **5-2　做法 A（建議）：用附的小程式合併。** 它會把 5 筆 hook 加進去，不動你原有的任何設定，可以重複執行。打：

   ```
   node src\bin\settings-hooks.mjs add "%USERPROFILE%\.claude\settings.json" "%CD%\src\bin\decision-log.mjs"
   ```

   看到 `{"ok":true,"added":5,"replaced":0}`（重複執行時 `replaced` 會是 5）就成功。如果看到「settings.json 不是合法的 JSON」，表示它沒改任何東西，改用做法 B。

   再打這行確認：

   ```
   node src\bin\settings-hooks.mjs check "%USERPROFILE%\.claude\settings.json"
   ```

   要看到 `"installed":5`。

   **5-2　做法 B：自己用記事本加。** 用記事本打開 `C:\Users\你的使用者名稱\.claude\settings.json`。
   - 如果裡面還沒有 `"hooks"`：在最外層的 `{` 後面加上下面整段（注意最後的逗號）。
   - 如果已經有 `"hooks"`：不要整段貼，而是把下面每個事件（`PreToolUse`、`PostToolUse`…）的**方括號裡的那一筆**加進你原有的同名事件的方括號裡，用逗號隔開；沒有的事件就整個加。
   - 把 `你的使用者名稱` 換成真的名字。路徑用斜線 `/`（不用打兩個反斜線）。

   ```json
   "hooks": {
     "PreToolUse": [
       { "matcher": "AskUserQuestion|mcp__.*wrap_up", "hooks": [ { "type": "command", "command": "node \"C:/Users/你的使用者名稱/pending-decisions-widget/src/bin/decision-log.mjs\"", "timeout": 15 } ] }
     ],
     "PostToolUse": [
       { "matcher": "AskUserQuestion", "hooks": [ { "type": "command", "command": "node \"C:/Users/你的使用者名稱/pending-decisions-widget/src/bin/decision-log.mjs\"", "timeout": 15 } ] }
     ],
     "PostToolUseFailure": [
       { "matcher": "AskUserQuestion", "hooks": [ { "type": "command", "command": "node \"C:/Users/你的使用者名稱/pending-decisions-widget/src/bin/decision-log.mjs\"", "timeout": 15 } ] }
     ],
     "PermissionRequest": [
       { "hooks": [ { "type": "command", "command": "node \"C:/Users/你的使用者名稱/pending-decisions-widget/src/bin/decision-log.mjs\"", "timeout": 130 } ] }
     ],
     "Notification": [
       { "matcher": "permission_prompt", "hooks": [ { "type": "command", "command": "node \"C:/Users/你的使用者名稱/pending-decisions-widget/src/bin/decision-log.mjs\"", "timeout": 15 } ] }
     ]
   },
   ```

   重點：`PermissionRequest` 的 `timeout` 要 **130**（其他 15）——手機核准功能會等人按；沒開那個功能時它照樣馬上結束。存檔後可以再跑上面的 `check` 指令確認是 `"installed":5`。

   **5-3　重開 Claude。** 已經開著的 Claude 對話不會載入新的 hook；關掉它們、重新開新的對話（這個步驟之後開的對話才有 Windows 通知）。

## 確認通知有跳

1. 螢幕角落看得到小工具的圖示。
2. 開一個**新的** Claude 對話，跟它說：「請用選項框問我一個問題（任何題目都行）」。
3. 你應該會看到三件事：
   - 右下角跳出 Windows 通知「有選項框等你回答（共 1 件）」（通知上寫的來源可能是「Windows PowerShell」，這是正常的）；
   - 小工具冒出紅色氣泡「有待決定囉！· 1 件」並叮一聲；
   - 點小工具的圖示，清單裡有那一題。
4. 回答選項框後，清單裡那一題會在幾秒內消失。
5. 再測「要你允許」：請 Claude「執行一個需要我允許的指令」（例如在一個沒設定過允許的資料夾裡建檔案），應該會跳「Claude 需要你的允許」。
6. 只有小工具有反應、沒有 Windows 通知：
   - Windows 通知可能被「勿擾／專注輔助」或防毒擋住（**未驗證**哪一個）；小工具本身不受影響。
   - 確認第 5 步的 `check` 是 `"installed":5`，而且這個對話是第 5 步**之後**才開的。
   - 打開 `…\pending-decisions-widget\src\data\error.log`（沒有這個檔＝沒出錯）。

## 更新（之後 GitHub 上有新版時）

1. **先關掉小工具：** 在小工具的圖示上按右鍵 →「結束浮窗」。
2. **抓最新版。** 在命令提示字元打：

   ```
   cd %USERPROFILE%\pending-decisions-widget
   git pull
   ```

   - 看到 `Already up to date.`＝已經是最新。
   - 你的 `config.json` 和 `src\data\` 裡的資料（清單、設定、你放的圖）不會被動到。
   - 如果 `git pull` 抱怨「local changes」：表示資料夾裡有檔案被改過。**不要硬蓋**，把畫面截圖，問維護這個專案的人。
   - 用 ZIP 安裝的人：重新下載 ZIP，解壓到**另一個新名字**的資料夾（例如加日期），再把舊資料夾的 `src\config.json` 複製過去；然後第 5 步的 hook 路徑要重做一次（做法 A 再執行一遍即可，會自動換成新路徑），確認後舊資料夾先留著不要刪。
3. **重開小工具：** 連點兩下 `start-widget.cmd`（有設開機自動啟動的話，下次開機自己會開）。
4. **hook 不用重做。** hook 指到資料夾裡的檔案，`git pull` 之後它自然就是新版；已經開著的 Claude 對話下一次觸發時就用新版。**只有 `CHANGELOG.md` 寫「hook 清單變了／新增 hook」時**，才要再跑一次第 5 步的做法 A（可重複執行，不會重複加）。

## 現有檔案缺什麼／要注意的（照程式看出來的）

- **一定要 Node.js 18 以上**（`install.ps1` 會檢查，這個做法沒有人檢查，所以第一步自己確認）。
- **`start-widget.cmd` 不檢查 Node.js**；找不到 Node 時小工具會開，但清單只顯示「找不到 Node.js」。
- **資料夾位置有點不同**：用這個做法時，設定檔和資料都在 `pending-decisions-widget\src\` 底下（`src\config.json`、`src\data\`），**不是** `~\.claude\pending-decisions\`。
- **資料夾名稱要含 `pending-decisions`**：`settings-hooks.mjs` 靠命令裡有這個字來認出「這是本工具的 hook」，之後才能乾淨地移除或重跑；用預設的 `git clone` 名字就符合。
- **hook 的 `timeout`**：`PermissionRequest` 要 130、其他 15（做法 A 會自動設好；做法 B 自己照上面寫）。
- **移除 hook 的方式**（要的時候）：`node src\bin\settings-hooks.mjs remove "%USERPROFILE%\.claude\settings.json"`（只拿掉本工具那 5 筆；動之前同樣先備份）。
- **Windows 通知靠 `toast.ps1`**：hook 會另外開一個隱藏的 PowerShell 來跳通知。防毒如果擋這個，通知會悄悄不出現，小工具和 hook 的記錄不受影響；它的錯誤不會寫進 `error.log`。是否真的會被擋：**未驗證**。
- 這份文件對應的版本：`CHANGELOG.md` 最上面的「未發布」之後。
